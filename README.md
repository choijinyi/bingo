# 이름 빙고 (Name Bingo)

200명 이상이 동시에 즐길 수 있는 실시간 이름 빙고 게임입니다.

## 사용 방법

### 진행자 (`/`)
1. 게임 이름을 입력하고 **게임 시작하기**를 누릅니다.
2. QR 코드와 입장 링크가 생성되고, 참가자가 제출한 이름이 실시간으로 들어옵니다(3초 폴링).
3. 참가자 이름 중 게임에 사용할 **25명을 탭해서 선택**합니다 (먼저 온 25명 자동 선택 지원).
4. **이 25명으로 게임 진행하기**를 누른 뒤 이름을 클릭해 호출합니다.
   - 호출된 이름은 빨간색으로 바뀌고 호출 순서 배지가 붙습니다.
   - 다시 클릭하면 호출이 취소되며, "이름 다시 선택"으로 선택 단계로 돌아갈 수 있습니다.

### 참가자 (`/play/[코드]`)
1. QR을 스캔해 입장한 뒤 자기 이름을 입력합니다. 이 이름이 진행자 화면에 표시됩니다.
2. 자기 이름과 함께 참여한 사람들의 이름을 직접 적어 25칸 빙고판을 완성합니다.
3. 진행자가 이름을 부르면 내 빙고판의 같은 이름이 **빨간색**으로 표시됩니다 (2초 폴링).
4. 가로/세로/대각선 한 줄이 완성되면 `n줄 빙고!` 배너가 나타납니다.

## 기술 구성
- **Next.js (App Router)** — 진행자/참가자 페이지
- **Supabase (Postgres)** — 게임 상태 저장, 참가자는 2초 간격 폴링으로 동기화
  - `bingo_games(code, title, names, called, …)` / `bingo_players(id, game_code, nickname, names, …)`
- **qrcode** — 입장 QR 코드 생성
- **Vercel** — 배포

## 개발

```bash
npm install
npm run dev
```

환경변수 없이도 동작하며(코드에 공개 anon 키 기본값 포함), 다른 Supabase 프로젝트를 쓰려면
`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`를 설정하세요.
